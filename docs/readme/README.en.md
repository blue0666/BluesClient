## BluesClient1.12

[中文](../../README.md) | English

---

A utility mod for RLCraft&RLCDregora, providing some modifications and quality-of-life features, with top development priority given to Dregora.

Generated from the Cleanroom Mod Dev Template. Special thanks to De6ris - this mod is modeled after the architecture and coding style of DebrisClient.

---

Default open-key is B+C, and if it conflicts, you can open the mod in the mod-list page and change it however you like.

Dependencies:

**RLCDregora**:Malilib required，[Malilib download](https://masa.dy.fi/tmp/minecraft/mods/malilib/malilib-forge-1.12.2-0.10.0-dev.23.jar)

**RLCraft**:Also requires FermiumBooter，[FermiumBooter download](https://modrinth.com/mod/fermiumbooter/versions)

**RLC MXAddons**:Some versions may already includes malilib, so make sure not to install it repeatedly.

**Very Important**:Please don't rename the mod and the dependencies, or add prefixes. Due to the mod loading sequence, adding prefixes make mods load before dependencies, causing crash because it cannot find dependencies.
