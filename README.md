## BluesClient1.12

---

Rlcraft/RlcDregora整合包辅助模组，提供了一些轮椅与自动化功能

由 Cleanroom Mod Dev Template 生成,特别鸣谢：De6ris，本mod参考了许多DebrisClient的架构与写法

---

配置开关B+C，如果有冲突，也可以先去mod列表里选中，也可以打开修改

前置mod：
德雷版需安装Malilib，MixinBooter

原版RLC还需要额外安装FermiumBooter


**特别强调**：请不要将mod改名，加中文，加前缀，由于mod加载顺序原理，加前缀会让mod先于依赖模组加载，导致找不到前置而崩溃
